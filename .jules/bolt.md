## 2024-05-19 - Synchronous I/O in MainActor Classes Anti-Pattern
**Learning:** In `@MainActor` Swift classes (like `HistoryManager` and `PresetManager`), performing synchronous file system operations (like `Data.write` and `FileManager.removeItem`) directly on the main thread causes UI hitches and blocks execution. Offloading this work to `Task.detached` is dangerous for sequential writes as it introduces data races.
**Action:** When refactoring disk I/O in MainActor classes, always use a dedicated serial background `DispatchQueue` (e.g., `ioQueue.async`) to maintain execution order and prevent UI blocking. Crucially, capture `@MainActor` state (like class properties) synchronously as local variables *before* dispatching the closure to avoid strict concurrency violations.

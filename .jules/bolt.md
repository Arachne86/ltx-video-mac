## 2024-12-05 - SwiftUI List Performance Optimization
**Learning:** In SwiftUI, using synchronous disk I/O (like `NSImage(contentsOf: url)`) directly in the view body of elements inside a scrollable list (like `LazyVGrid` or `List`) blocks the main thread. This leads to a stuttering UI and degraded user experience during scrolling, especially as the number of items grows. Additionally, while `AsyncImage` exists, it lacks built-in caching and can cause constant reloading/flickering for local file URLs in lists.
**Action:** Always load local images asynchronously for list elements using a `.task(id:)` modifier. To prevent strict concurrency violations in modern Swift, perform the disk I/O inside `Task.detached(priority: .background)`, return the result, and then assign it back to a main-actor-bound `@State` property using `MainActor.run` or by directly setting it since the task inherits the actor context if properly awaited.

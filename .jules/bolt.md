## 2025-05-18 - Fix SwiftUI @MainActor UI Hitches by Offloading File I/O
**Learning:** In `@MainActor` classes like `HistoryManager` and `PresetManager`, performing synchronous file system operations (JSON encoding, writing, deleting) blocks the main thread, causing significant UI hitches during rendering. We should offload these. We must avoid `Task.detached` for sequential file writes, as it executes concurrently and can introduce data races (out-of-order writes) when saving updates.
**Action:** When saving or deleting files triggered from the main actor, always use a dedicated serial `DispatchQueue` to maintain write order and avoid blocking the main thread. Always capture state synchronously on the main thread (e.g. `let currentResults = results`) before offloading work to the `async` closure.

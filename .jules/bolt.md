## 2024-03-01 - Offloading Synchronous I/O in @MainActor State Managers
**Learning:** In `@MainActor` state managers (like `HistoryManager` and `PresetManager`), performing synchronous file system operations like JSON encoding and `.write(to:)` blocks the main thread, causing severe UI hitching when saving history or presets. However, using `Task.detached` to offload this work is a common anti-pattern because detached tasks run concurrently, leading to data races and out-of-order writes.
**Action:** Always offload synchronous file I/O to a dedicated background serial `DispatchQueue` (e.g., `ioQueue`). Capture the necessary state (like the encoded `Data` or URL paths) synchronously on the main actor first, then dispatch the write or delete operation to the serial queue using `.async`. This guarantees sequential execution without blocking the UI thread.

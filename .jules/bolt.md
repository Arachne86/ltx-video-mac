## 2024-05-18 - [Offloading Synchronous File I/O from @MainActor Classes]
**Learning:** In SwiftUI, classes marked with `@MainActor` (like `HistoryManager` and `PresetManager`) run all their properties and methods on the main thread. Performing synchronous disk operations (like `JSONEncoder().encode` and `Data.write`) inside these classes blocks the main thread, causing UI hitches and frame drops. When attempting to offload this via `Task.detached`, accessing self properties concurrently causes strict concurrency warnings/errors.
**Action:** Always create a dedicated serial background `DispatchQueue` (e.g., `ioQueue`) in the class. Synchronously capture necessary state (like the current `results` array and `fileURL`) as local variables *before* the async closure, and then dispatch the heavy encoding and disk writing tasks to that `ioQueue.async` block. Do not capture `self` inside the background queue.

## 2024-03-24 - [Title: Synchronous MainActor File I/O Deadlock Vulnerability]
**Learning:** [Insight: In Swift, while `@MainActor` serializes property access, performing synchronous disk operations (`Data(contentsOf:)`, `.write(to:)`, `FileManager.removeItem()`) directly inside MainActor functions blocks the UI thread immediately. Offloading these correctly requires careful synchronization: you cannot use `Task.detached` because concurrent file writes can cause data corruption or race conditions. A private serial `DispatchQueue` is required. Furthermore, you MUST synchronously capture actor-isolated state on the main thread BEFORE entering the background closure to avoid strict concurrency violations or race conditions reading changing state mid-write.]
**Action:** [How to apply next time: When offloading MainActor I/O in Swift: 1) create a private serial `DispatchQueue`, 2) capture all necessary `self` properties synchronously as local constants (`let dataToSave = self.data`), 3) dispatch to the queue (`ioQueue.async { ... }`), 4) use `options: .atomic` when writing critical JSON files to prevent partial write corruption.]

## 2024-06-01 - Avoid Synchronous Disk I/O in Scrollable SwiftUI Lists
**Learning:** Performing synchronous disk reads (e.g., `NSImage(contentsOf:)`) directly within a SwiftUI view's body or subview construction, especially in scrollable lists (`List`, `LazyVStack`), blocks the main thread, leading to noticeable UI stuttering and frame drops as cells are rendered or recycled. While `AsyncImage` exists, it's poorly suited for local file URLs in fast-scrolling lists because it lacks in-memory caching and causes visual flickering upon cell reuse.
**Action:** When loading local images for scrollable views, offload the synchronous I/O to a background thread using `.task(id:)` and `Task.detached(priority: .background)`. Crucially, manage the loaded image via local `@State`, set it to `nil` immediately when the task starts to clear stale images from recycled cells, and check `!Task.isCancelled` before assigning the newly loaded image back to `@State` to prevent race conditions during rapid scrolling.

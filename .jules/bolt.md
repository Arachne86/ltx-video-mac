## 2024-03-15 - [Optimize NSImage loading in SwiftUI lists]
**Learning:** Using synchronous `NSImage(contentsOf:)` inside a scrollable view (like `ForEach` in `HistoryView` rendering `HistoryThumbnailView`) blocks the main thread during disk I/O, causing UI stuttering and poor scrolling performance, especially when there are many items.
**Action:** Do NOT use `NSImage(contentsOf:)` directly in the view body. Do NOT use `AsyncImage(url:)` for local file URLs in scrollable lists because it lacks in-memory caching and causes flickering during view recycling. Instead, use a `@State` variable for the `NSImage` and load it asynchronously using `.task { ... }` with `Task.detached(priority: .background)`. Ensure you explicitly set the state to `nil` before the async load to prevent stale image flicker, and check `!Task.isCancelled` before assigning the result to prevent race conditions during rapid scrolling.

## 2025-05-30 - Prevent Main Thread Blocking in @MainActor state managers
**Learning:** In `@MainActor` classes (like `HistoryManager` and `PresetManager`), synchronous file system operations (like `JSONEncoder().encode()` and `Data.write(to:)`) block the main thread and can cause UI hitches. Using `Task.detached` to offload this work is an anti-pattern for sequential writes because it executes concurrently and can introduce data races or write-ordering issues.
**Action:** Always offload these synchronous I/O operations to a dedicated serial `DispatchQueue` (e.g., `ioQueue`). Crucially, capture any necessary state (like the data array or URLs) synchronously as local variables on the main thread *before* dispatching to the background queue to avoid strict concurrency warnings about capturing `self` in the async closure.

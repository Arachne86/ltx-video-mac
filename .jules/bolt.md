## 2024-04-26 - Offloading @MainActor file I/O safely
**Learning:** In `@MainActor` Swift classes like `HistoryManager` and `PresetManager`, performing synchronous file operations (like JSON encoding and disk writing) on the main thread causes UI hitches. To fix this without introducing strict concurrency warnings, you must first synchronously capture the state as local variables on the main thread, and then offload the write operation using a background serial `DispatchQueue` alongside the `.atomic` option to prevent corruption. Using `Task.detached` for sequential file writes is an anti-pattern because it executes concurrently, introducing data races.
**Action:** Always offload disk I/O in main actor classes to a dedicated serial background queue, capturing necessary state synchronously before dispatching.

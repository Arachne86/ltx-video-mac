## 2024-05-28 - Optimize Synchronous Disk I/O on Main Actor
**Learning:** In `@MainActor` classes (like `HistoryManager` and `PresetManager`), performing synchronous file system operations such as reading/writing JSON and deletions directly on the main thread causes UI hitches and lack of responsiveness. However, using `Task.detached` blindly can introduce critical data races where older snapshots overwrite newer ones because tasks lack execution order guarantees.
**Action:** Offload file system operations to a serial background queue (e.g., `DispatchQueue(label: qos: .background)`). This moves the heavy work off the main thread while guaranteeing write order serialization. Also, use the `.atomic` writing option to ensure data integrity and prevent file corruption during partial writes. Ensure state dependencies are captured locally before offloading.
